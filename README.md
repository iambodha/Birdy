## 🌟 Features

**Birdy** provides real-time aircraft tracking with custom scraping technology to avoid expensive API fees.

- **🛫 Real-time Aircraft Tracking** - Live scraping of aircraft positions and flight data
- **🗺️ Interactive Map Visualization** - Frontend map displaying live airplane locations
- **📈 Route Visualization** - Visual representation of flight paths over time
- **✈️ Aircraft Metadata** - Detailed information including call signs and aircraft IDs
- **☁️ Cloud-Hosted Backend** - Scalable scraping infrastructure on Oracle Cloud
- **🔄 Individual Aircraft Tracking** - Direct tracking system for fresher, more accurate data
- **💰 Cost-Effective Solution** - Custom scraper to avoid expensive flight tracking APIs

## 🚀 Key Highlights

- **Real-time Data** - Live aircraft position updates without relying on stale API data

## ⚠️ Project Status

**This project has been archived due to sustainability challenges.**

The project was discontinued because:
- High-quality flight data requires expensive API subscriptions
- Web scraping approaches led to IP bans from data sources
- Sustainable data collection would require owning ADSB Exchange servers or paying substantial API fees

While the technology successfully demonstrated real-time aircraft tracking capabilities, the cost and legal barriers to reliable data access made long-term operation unfeasible.
